# E-MOGRAM - Sentiment Analysis for Mental Health Support

E-MOGRAM is a web application developed for analyzing the sentiment of social media posts using Natural Language Processing (NLP) and sentiment analysis techniques. The system primarily focuses on detecting emotional distress from social media posts to support mental health.

This project uses the **VADER Sentiment Intensity Analyzer** for sentiment classification and a pre-trained NLP model from **Hugging Face** for text analysis.

## Project Overview

E-MOGRAM offers the following features:
- **Social Media Post Analysis:** Analyzes posts from platforms like Facebook to detect positive, neutral, or negative sentiments.
- **Real-time Alerts:** Sends alerts if emotional distress or negative sentiments are detected.
- **User Interaction:** A web-based interface that displays emotional analytics and alerts.
